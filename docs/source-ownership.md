# CMP Server source ownership

This public-candidate source is the standalone Core repository engine.
CMP Cloud owns managed identity, CMP Connect and remote providers, WSS,
agent coordination/work contracts and session archiving.

The development-only working implementations previously found in the
private legacy repository have been preserved under cmp-cloud's private
migration assets and the original private archived Git repository. The
new public repository was created from reviewed source with a fresh history.
